== Scope

This document specifies an extension to the <<OAFeat-1,OGC API - Features - Part 1: Core>> standard that defines the behavior of a server that supports sorting of query responses based on a specified set of properties and sort orders.

This document defines

* A query parameter (`sortby`) for specifying the list of properties upon which the results of a query should be sorted.
* A notation for indicating the sort order (ascending or descending) of each specified sort property.
* How servers declare a default sort order.

The set of properties that can be used to construct a sorting expression ("sortables") is published by a Web API in the Sortables resource specified in <<OAFeat-5,OGC API - Features - Part 5: Schemas>>.

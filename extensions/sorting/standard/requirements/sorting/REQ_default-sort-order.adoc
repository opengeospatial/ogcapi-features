[[req_sorting_default-sort-order]]
[width="90%",cols="2,6a"]
|===
^|*Requirement {counter:req-id}* |*/req/sorting/default-sort-order*
^|Condition |A default sort order is declared for the sortable resource.
^|A |The default sort order SHALL be an array of strings according to the following OpenAPI Specification 3.0 fragment:

[source,YAML]
----
type: array
items:
  type: string
----

^|B |Each string in the array SHALL be the name of a sortable, optionally preceded by a `+` or a `-`.
^|C |If the parameter `sortby` is not provided, the resources in the response SHALL be ordered as if the parameter `sortby` had been provided with the strings of the default sort order as its value.
|===

|===
^|*Recommendation {counter:rec-id}* |*/rec/sorting/stable-order*
^|A |If the sort keys do not determine a unique order of the resources, the server SHOULD order resources with the same values of the sort keys consistently, for example, by using the identifier of the resources as an additional, last sort key.

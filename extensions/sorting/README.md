# OGC API - Features - Part 8: Sorting

This folder contains the content for the candidate standard [OGC API - Features - Part 8: Sorting](https://docs.ogc.org/DRAFTS/24-030.html).

The document is in the folder "standard", the document is [standard/24-030.adoc](https://github.com/opengeospatial/ogcapi-features/blob/master/extensions/sorting/standard/24-030.adoc).

## Status

The document is a draft.

## Overview

Part 8 (Sorting) specifies the query parameter "sortby". The parameter sorts the features in a response by one or more properties, each in ascending or descending order.

The Sortables resource, specified in [Part 5 (Schemas)](../schemas), lists the properties that can be used for sorting.

[[clause-conformance]]
== Conformance

This standard defines the following conformance classes:

   * <<clause-adhoc-query,Ad-hoc query>>

   * <<clause-stored-query,Stored query>>

   * <<clause-multi-resource-response,Multi-resource response>>

   * <<clause-join-response,Join Response>>

   * <<clause-parameterized-stored-query,Parameterized stored query>>

   * <<clause-manage-stored-query,Manage stored query>>

   * <<clause-query-expression-json,Query Expression JSON>>

   * <<clause-http-query-method,The HTTP QUERY method>>

The standardization target is "Web APIs".

Conformance with this standard shall be checked using all the relevant tests
specified in <<ats,Annex A>> of this document. The framework, concepts, and
methodology for testing, and the criteria to be achieved to claim conformance
are specified in the OGC Compliance Testing Policies and Procedures and the
OGC Compliance Testing web site.

[[req_stored-query_get-op]]
[width="90%",cols="2,6a"]
|===
^|*Requirement {counter:req-id}* |*/req/stored-query/get-op*
^|A |For every stored query in the stored queries response (path `/query`), the server SHALL support the HTTP GET operation at the path `/query/{queryId}`, where `{queryId}` is the `id` of the stored query (JSONPath: `$.queries[*].id`).
|===

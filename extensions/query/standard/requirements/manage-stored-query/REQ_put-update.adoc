[[req_manage-stored-query_put-update]]
[width="90%",cols="2,6a"]
|===
^|*Requirement {counter:req-id}* |*/req/manage-stored-query/put-update*
^|Condition |The stored query has the value `true` for `mutable` in the stored queries response (JSONPath: `$.queries[*].mutable`).
^|A |The server SHALL support the HTTP PUT operation at the path `/query/{queryId}`, where `{queryId}` is the `id` of the stored query (JSONPath: `$.queries[*].id`).
|===

[[req_manage-stored-query_delete-op]]
[width="90%",cols="2,6a"]
|===
^|*Requirement {counter:req-id}* |*/req/manage-stored-query/delete-op*
^|Condition |The stored query has the value `true` for `mutable` in the stored queries response (JSONPath: `$.queries[*].mutable`).
^|A |For every stored query in the stored queries response (path `/query`), the server SHALL support the HTTP DELETE operation at the path `/query/{queryId}`, where `{queryId}` is the `id` of the stored query (JSONPath: `$.queries[*].id`).
|===

[[req_manage-stored-query_definition-op]]
[width="90%",cols="2,6a"]
|===
^|*Requirement {counter:req-id}* |*/req/manage-stored-query/definition-op*
^|A |For every stored query in the stored queries response (path `/query`), the server SHALL support the HTTP GET operation at the path `/query/{queryId}/definition`, where `{queryId}` is the `id` of the stored query (JSONPath: `$.queries[*].id`).
|===

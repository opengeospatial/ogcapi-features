[[req_http-query-method_parameterized-query-op]]
[width="90%",cols="2,6a"]
|===
^|*Requirement {counter:req-id}* |*/req/http-query-method/parameterized-query-op*
^|A |For every stored query identified in the stored queries response (path `/query`), the server SHALL support the HTTP QUERY operation at the path `/query/{queryId}`.
^|B |The parameter `queryId` is each `id` property in the stored queries response (JSONPath: `$.queries[*].id`).
^|C |The content type of the QUERY body shall be `application/x-www-form-urlencoded`.
|===

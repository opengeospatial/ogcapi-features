[[req_http-query-method_parameterized-query-op]]
[width="90%",cols="2,6a"]
|===
^|*Requirement {counter:req-id}* |*/req/http-query-method/parameterized-query-op*
^|A |For every stored query in the stored queries response (path `/query`), the server SHALL support the HTTP QUERY operation at the path `/query/{queryId}`, where `{queryId}` is the `id` of the stored query (JSONPath: `$.queries[*].id`).
^|B |The server SHALL accept a request body with the content type `application/x-www-form-urlencoded`.
|===

[[req_parameterized-stored-query_parameters-op]]
[width="90%",cols="2,6a"]
|===
^|*Requirement {counter:req-id}* |*/req/parameterized-stored-query/parameters-op*
^|A |For each stored query in the stored queries response (path `/query`), the server SHALL support the HTTP GET operation at the path `/query/{queryId}/parameters`, where `{queryId}` is the `id` of the stored query (JSONPath: `$.queries[*].id`).
|===

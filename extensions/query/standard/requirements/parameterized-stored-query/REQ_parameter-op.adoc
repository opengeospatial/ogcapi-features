[[req_parameterized-stored-query_parameter-op]]
[width="90%",cols="2,6a"]
|===
^|*Requirement {counter:req-id}* |*/req/parameterized-stored-query/parameter-op*
^|A |For each parameter of each stored query in the stored queries response (path `/query`), the server SHALL support the HTTP GET operation at the path `/query/{queryId}/parameters/{parameterId}`. `{queryId}` is the `id` of the stored query (JSONPath: `$.queries[*].id`). `{parameterId}` is a key of `parameters` in the response of `/query/{queryId}/parameters` (JSONPath: `$.parameters`).
|===

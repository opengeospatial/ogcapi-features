[[req_parameterized-stored-query_parameters-url-mapping]] 
[width="90%",cols="2,6a"]
|===
^|*Requirement {counter:req-id}* |*/req/parameterized-stored-query/parameters-url-mapping* 
^|A |Each parameter name of a stored query (each key of `parameters`, JSONPath: `$.queries[*].parameters`) SHALL be a valid URI query parameter name as defined in https://www.rfc-editor.org/rfc/rfc3986.html[Uniform Resource Identifier (URI): Generic Syntax].
|===

== Requirements Class "Geometry Simplification"

[cols="2,7",width="90%"]
|===
^|*Requirements Class* |http://www.opengis.net/spec/{standard}/{m_n}/req/{req-class} 
|Target type |Web API
|===

The Requirements Class "Geometry Simplification" specifies the "zoom-level" query parameter. 

The value of the query parameter is a zoom level that identifies the map scale at which the requesting client will render geometries on a map.

The query parameter can be applied to web resources that can be represented as an object with one or more spatial properties or to resources that are collections of such objects; for example, a collection of features or a single feature.

[source,YAML]

include::schema/zoom-level.yaml[]

|===

NOTE: Decimal values are allowed as zoom levels, not just integers.

:req: response
[#req_{req-class}_{req}]
[width="90%",cols="2,7a"]
|===
^|*Requirement {counter:req-num}* |/req/{req-class}/{req}
^|A | If the query parameter "zoom-level" is provided, geometries in the response SHALL be simplified so that they are suitable for rendering on a map at the scale 1:_s_, where _s_ = 559 082 264.028 717 / 2^_z_^ and _z_ is the value of the query parameter "zoom-level".
^|B | The geometry type of the simplified geometry SHALL be consistent with the allowed geometry types for a geometry in the schema of the resource, if one is specified. 
^|C | If the query parameter "zoom-level" is provided and the web resource is a collection of objects, the objects in the response SHALL be a subset of the objects in the response to the same request without the query parameter "zoom-level".
|===

The zoom level is a measure of how far the map is zoomed in or out. The map scale is the ratio of a distance on the map to the corresponding distance on the ground. If the zoom level increases by one, the scale denominator halves.

<<zoom_levels>> shows the scale denominators of the integer zoom levels. This Standard uses the zoom level instead of the scale denominator, because in web mapping zoom levels are more commonly used and more intuitive than map scales. The scale denominators are those of the "WebMercatorQuad" tile matrix set at the equator, see <<OGC17-083r4>>.

The zoom level is only a shorthand for the scale denominator. The level of detail of the simplified geometries does not depend on the location of the geometries, on the projection of the map or on the coordinate reference system of the response.

NOTE: On a map in the Web Mercator projection, the map scale increases with the distance from the equator. For example, at a latitude of 60°, the scale is twice the scale at the equator. A client that displays such a map far from the equator can request a higher zoom level, for example, one zoom level higher at a latitude of 60°.

The simplification of geometries is a lossy operation. The simplified geometries are approximations of the original geometries. The simplification will typically reduce the number of vertices in a curve or a surface ring. The degree of simplification of geometries is implementation-dependent. Arcs, for example, in circular strings, can be approximated by line segments, if the schema of the resource allows the resulting geometry type (see requirement `/req/zoom-level/response`, sub-requirement `B`).

Simplification can result in invalid geometries, for example, rings that intersect themselves. In addition, neighbouring geometries with a shared boundary are typically simplified independently of each other, which can result in gaps or overlaps along the boundary.

:rec: valid-geometry
[#rec_{req-class}_{rec}]
[width="90%",cols="2,7a"]
|===
^|*Recommendation {counter:rec-num}* |/rec/{req-class}/{rec}
^|A | If the query parameter "zoom-level" is provided, the simplified geometries SHOULD be valid geometries of their geometry type.
|===

In addition to simplifying the geometries, a server can omit objects that are not relevant on a map at the zoom level, for example, minor roads or small buildings at small scales. This is similar to vector tiles, where the server determines which features are included in a tile at a zoom level. Which objects are omitted, if any, is determined by the server. A client that needs all objects, for example, for an analysis, does not use the query parameter "zoom-level".

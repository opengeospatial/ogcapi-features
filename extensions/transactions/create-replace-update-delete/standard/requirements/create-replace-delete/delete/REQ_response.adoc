[[req_create-replace-delete_delete-response]]          
[width="90%",cols="2,6a"]
|===
^|*Requirement {counter:req-id}* |*/req/create-replace-delete/delete-response*     
^|A |If the operation is executed immediately, a successful execution of the operation SHALL be reported as a response with a HTTP status code `200` or `204`.
^|B |If the operation is not executed immediately, but is accepted for processing at a later time (see Permission <<per_create-replace-delete_async,/per/create-replace-delete/async>>), the response SHALL have a HTTP status code `202`.
|===

|===
^|*Requirement {counter:req-id}* |*/req/return-resource-representation-in-response/preference-applied*
^|A |If the server has applied the `return` preference of a request when processing the request, the response SHALL include the `Preference-Applied` header (https://www.rfc-editor.org/rfc/rfc7240#section-3[section 3 of RFC 7240]) with the preference that was applied.
|===

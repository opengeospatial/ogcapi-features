[#rc_{req-class}]
== Requirements Class "Property Selection"

[cols="2,7",width="90%"]
|===
^|*Requirements Class* |http://www.opengis.net/spec/{standard}/{m_n}/req/{req-class} 
|Target type |Web API
|===

The Requirements Class "Property Selection" specifies the query parameters "properties" and "exclude-properties".

The query parameter "properties" takes a comma-separated list of property names that are to be included in the response. Properties where the name is not included in the query parameter value are in general not included in the response.

The query parameter "exclude-properties" takes a comma-separated list of property names that are to be omitted from the response. All other properties are included in the response. This is useful, if a resource has many properties and only a few of them are not needed, for example, a geometry with many coordinates.

The two query parameters cannot be combined in a request.

The query parameters can be applied to web resources that can be represented as an object with properties or to resources that are collections of such objects; for example, a collection of features, a single feature or a vector tile.

The list of valid property names can be determined from the API definition or, if a schema of the returnables is available, from the JSON Schema according to <<OAFeat-5,OGC API - Features - Part 5: Schemas>>, Requirements Class "Returnables and Receivables".

:req: response
[#req_{req-class}_{req}]
[width="90%",cols="2,7a"]
|===
^|*Requirement {counter:req-num}* |/req/{req-class}/{req}
^|A | The query parameter "properties" is optional. If it is not provided, all properties SHALL be returned.
^|B | If the query parameter "properties" is provided, only the selected returnable properties included in the parameter value SHALL be returned.
^|C | If the name of an object-valued property is selected, the complete object SHALL be returned. If properties inside an object-valued property are selected, only the selected properties of the object SHALL be returned.
|===

:req: exclude-response
[#req_{req-class}_{req}]
[width="90%",cols="2,7a"]
|===
^|*Requirement {counter:req-num}* |/req/{req-class}/{req}
^|A | If the query parameter "exclude-properties" is provided, the returnable properties included in the parameter value SHALL NOT be returned.
^|B | If the query parameter "exclude-properties" is provided, all returnable properties that are not included in the parameter value SHALL be returned.
^|C | If the name of an object-valued property is excluded, the complete object SHALL NOT be returned. If properties inside an object-valued property are excluded, only the excluded properties of the object SHALL NOT be returned.
|===

:req: exclusive-parameters
[#req_{req-class}_{req}]
[width="90%",cols="2,7a"]
|===
^|*Requirement {counter:req-num}* |/req/{req-class}/{req}
^|A | If a request includes both query parameters "properties" and "exclude-properties", the server SHALL respond with status code 400 (Bad Request).
|===

:per: required-properties
[#per_{req-class}_{per}]
[width="90%",cols="2,7a"]
|===
^|*Permission {counter:per-num}* |/per/{req-class}/{per}
^|A | By deviation from requirement `/req/properties/response`, sub-requirement `B`, and requirement `/req/properties/exclude-response`, sub-requirement `A`, the response MAY include properties that have not been requested in the query parameter "properties" or that have been excluded in the query parameter "exclude-properties", if this is required by the media type of the response.
|===

:per: unknown-properties
[#per_{req-class}_{per}]
[width="90%",cols="2,7a"]
|===
^|*Permission {counter:per-num}* |/per/{req-class}/{per}
^|A | If the value of the query parameter "properties" or "exclude-properties" includes unknown properties, the server MAY either return a 400 (Bad Request) response or ignore the unknown properties.
|===

====

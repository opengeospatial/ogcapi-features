==== Operation

As per the <<OAFeat-1,OGC API - Features - Part 1: Core>> Standard, features are accessed using the HTTP GET method via the `/collections/{collectionId}/items` path (see https://docs.ogc.org/is/17-069r4/17-069r4.html#_items[Features]).

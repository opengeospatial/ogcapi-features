# OGC API - Features - Part 9: Text Search

This folder contains the content for the candidate standard [OGC API - Features - Part 9: Text Search](https://docs.ogc.org/DRAFTS/24-031.html).

The document is in the folder "standard", the document is [standard/24-031.adoc](https://github.com/opengeospatial/ogcapi-features/blob/master/extensions/text-search/standard/24-031.adoc).

## Status

The document is a draft.

## Overview

Part 9 (Text Search) specifies the query parameter "q". The parameter selects resources that contain one or more search terms in their text properties.

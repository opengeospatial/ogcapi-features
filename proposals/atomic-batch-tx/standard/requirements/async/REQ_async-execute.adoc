[[req_async-transactions_execution]]
[width="90%",cols="2,6a"]
|===
^|*Requirement {counter:req-id}* |*/req/async-transactions/execution*
^|A |The server SHALL NOT execute a transaction asynchronously, unless the request includes the HTTP https://datatracker.ietf.org/doc/html/rfc7240#section-2[`Prefer`] header with a https://datatracker.ietf.org/doc/html/rfc7240#section-4.1[`respond-async`] preference.
|===

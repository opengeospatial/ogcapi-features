[[req_transactions_post-content-type]]
[width="90%",cols="2,6a"]
|===
^|*Requirement {counter:req-id}* |*/req/transactions/post-content-type*
^|A |The server SHALL infer the media type of the request body from the `Content-Type` header.
^|B |The server SHALL return a 400 client error if no `Content-Type` header is provided in the request.
|===

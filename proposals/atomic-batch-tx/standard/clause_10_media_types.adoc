[[mediatypes]]
== Media Types

See <<OAFeat-1,OGC API - Features - Part 1: Core>>, Clause 10.

The following table lists the media types of the resources specified in this Standard.

[#tab_media_types,reftext='{table-caption} {counter:table-num}']
.Media types
[cols="45,20,35",options="header"]
|===
|Resource |Media type |Specified in
|Transaction (request body of a POST request to the transactions endpoint) |`application/ogc-tx+json` |<<sc_json>>
|Transaction report (response to a transaction, results of an asynchronous transaction) |`application/json` |<<sc_json>>, <<sc_async-transactions>>
|Status information of an asynchronous transaction |`application/json` |<<sc_async-transactions>>
|Schema of the features in a collection |`application/schema+json` |<<schemas>>
|===

The features in insert and replace actions are part of the transaction. In the JSON encoding, they are GeoJSON features (see <<feature-geojson>>) and are not identified by a separate media type.

NOTE: The media type for transactions is not final.

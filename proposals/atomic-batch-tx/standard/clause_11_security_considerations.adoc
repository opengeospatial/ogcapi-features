== Security Considerations

See <<OAFeat-1,OGC API - Features - Part 1: Core>>, Clause 11, and <<OAFeat-4,OGC API - Features - Part 4: Create, Replace, Update and Delete>>, Clause 13. The considerations for create, replace, update and delete operations apply to transactions, too.

Since transactions change resources and not "just" query them, servers will in almost all cases restrict access to the transactions endpoint.

A transaction can affect several collections. The server checks the privileges of the user for each action.
